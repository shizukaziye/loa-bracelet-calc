Dequeue

Evicts by key substring, deliberately: some queued names are mojibake and their key cannot be rebuilt from a clean string. The order snapshot is deleted afterwards.

Seed the board

Reads the seed file from this origin and POSTs it. Every entry is re-scored by the Worker from its raw stats, so the response reports each entry's delta against the file.

Rescore

Marks stored rows for client rescoring. Cheap — the Worker keeps the raw stats, so nothing is refetched.
